Other interface changes

  • Status chip rows replaced by a single Status dropdown with live counts, on Leave Requests, Team's Leaves and Team's Shift.
  • Reason and Notes clamp to two lines with the full text on hover. The tooltip is fixed-positioned so the table's horizontal scroll cannot clip it, and only appears when the text is genuinely cut off.
  • Leave attachments open in a preview modal — images inline, PDFs in a frame — instead of downloading.
  • Profile gained a title bar with an Edit Profile button and lost the active / online indicator.

  • Two native confirm() dialogs (Shifts, HR Announcements) replaced with branded modals.

3  Time Entries (new module)

A NetSuite-style weekly timesheet replaced the old stand-up feature.

  • New tables — time_types, timesheets, timesheet_entries.
  • Time Entries — the personal grid: project, task, time type, memo and seven day columns, with draft → pending → approved.
  • Team's Time Entries — a weekly roster that includes people who never started a sheet, drillable into one person's read-only grid, with CSV export.
  • Approval lands in the Dashboard Requests queue alongside leaves and shift changes.

4  Overtime removed

The company does not file overtime; compensatory time off (CTO) is granted directly on leave credits instead. Removed: the overtimes table, its model, policy, resource, request, seeder, three controllers, three Vue screens and the dead 'overtime' value in the for_approvals type enum.

5  Glip and RingCentral removed

Glip is no longer used, so the integration was removed in full.

  • RingCentralService deleted — roughly 800 lines and 13 send methods.
  • Call sites removed from AttendanceService (clock in, clock out, break start, break end), DashboardController (leave and correction approve / reject), MyAttendanceController, MyLeavesController, MyStandupController, AuthController and the auto-approve command.
  • glip_url dropped from both users and projects, and removed from the user screens, resource, form requests and seeders.
  • The ringcentral block removed from config/services.php.
There are now no outbound notifications. Attendance, leave and approval events no longer notify anyone. The login magic link still goes out by email, so sign-in is unaffected. Two messages that claimed a notification had been sent were corrected.

6  Project Manager removed

The role does not exist at the company. pm_id and the projectManager relation were removed from the model, resource, service eager loads, both form requests, the seeder and the Projects screen, and the column was dropped.

Side effect worth knowing: the seeder previously skipped any project whose project manager could not be found. With the check gone it now seeds all 14.

7  Migration consolidation

Since the project is pre-production, alter-table migrations were folded into the create migrations they amend, taking 40 files down to 23 — all now create_*.

Folded intoWhat moved in
create_users_tableemployment_status; glip_url removed
create_projects_tablepm_id and glip_url removed
create_attendances_tabletime_in/time_out widened to datetime
create_leaves_tablecancelled status, cancelled_at, cancelled_by
create_attendance_corrections_tableThe two lunch-break columns
create_leave_credits_tablePTO (days) and CTO (hours)
RolePermissionSeederAll 16 permissions from 4 permission migrations

Five overtime migrations were deleted outright — the table was created, altered three times and then dropped, which is a no-op on a fresh database. Two of those five were byte-identical duplicates committed 32 seconds apart.

Verified by snapshotting all 375 columns across 40 tables, rebuilding from scratch, and diffing: 375 columns before and after, with only the two intended differences.

9  Known issues not fixed

Found during this work, reported, and deliberately left alone:

  • Announcement thumbnails leak titles to a third party. The seeder writes image paths for files it never creates, and the dashboard falls back to ui-avatars.com with the announcement title in the query string.
  • Attendance month filter silently clears a typed date range.
  • attendance_date serialises as a UTC timestamp, so browsers outside the app timezone mislabel rows by a day. Three components read it.
  • Team's Shift has no applied filter option; those rows appear only under All Statuses.
  • User creation requires a resolvable email domain (email:rfc,dns), so seeded .test accounts cannot be created through the UI.
  • for_approvals switch handles values its enum forbids — attendance and shift are unreachable branches.
  • No HR screen for Time Types — the table, model and read API exist, the management screen does not.

10  What this means for your database

A rebuild is required. Because alter-table migrations were folded into the create files, a database that already ran the old set is inconsistent with the files. php artisan migrate will not reconcile it — run php artisan migrate:fresh --seed.

Anyone with a local copy of the project needs to do the same.

Do not re-run LeaveSeeder on its own. It is not idempotent across days: relative dates shift and it duplicates leaves, and deleting the duplicates does not reverse the leave-credit observer. Use migrate:fresh --seed.
